# Agent Atelier visual specification

Brand mark: use the original ImageGen pixel-art A/atelier logo in `public/assets/logo.png` for the sidebar and loading screen, and its matching `app/favicon.ico` for browser tabs. Forest green, ivory, and an amber window connect the mark to the office palette. Generation prompt and asset sizes: `logo.md`.

Reference: `concept.png` (1536 × 1024). Thai UI, light ivory application background, white navigation and inspector, forest-green primary action, charcoal content, restrained gray borders. Body and controls use a Thai-capable system sans-serif, 14px controls, 16px reading text, 30px main title, 20px section titles. Spacing uses 4/8/12/16/24/32px; 8px radii and thin borders.

Desktop composition: 200px left rail, fluid main area, 310px selected-member inspector. The primary focal point is a warm wood pixel office. Main header, project selector and room toolbar precede the scene. A three-column task board follows it. On smaller screens navigation becomes a horizontal rail and the inspector stacks after the scene. All interactive labels, status, forms and nameplates are HTML; the office scene is Phaser.

Primary labels: ออฟฟิศของคุณ; ทีม AI ของคุณ พร้อมทำงานไปด้วยกัน; สร้างงาน; พื้นที่ทำงาน; จัดห้อง; เพิ่มสมาชิก; งานในทีม; รอเริ่ม; กำลังทำ; เสร็จแล้ว; ข้อมูลสมาชิก; ตั้งค่าสมาชิก; Model; งานปัจจุบัน; ข้อความถึง; ส่งข้อความ; กิจกรรมล่าสุด. Navigation: ออฟฟิศ, งาน, ทีมแชต, ตารางงาน, ความทรงจำ, การอนุมัติ, โปรเจกต์, เชื่อมต่อ. Icons: Lucide outline, 20px, 1.8px stroke.

Intentional functional extensions: connection/retry status and stop-team action; error/interrupted task state; dialogs for agent settings, task creation/detail, schedule, project, memory, external approval and Google setup. These reuse the same controls, spacing, palette and typography. Room furniture and characters are separate generated assets so users can rearrange furniture and change avatars. The room is not a flattened screenshot. Character walk routes, progress markers and meeting positions are derived from real runtime state. Reduced-motion preference disables animation.

Avatar editor: member forms offer ตัวละครเดิม / สร้างตัวละคร with pressed button states and paired face/full-body previews. Existing members keep their original sprites until explicitly changed and saved. The local composer uses fixed 32×32 pixel layers scaled to 96×96 without smoothing: one body/outfit, four hair styles (short, bob, long, curly), six skin tones, hair/shirt colors, and optional glasses. Skin swatches have Thai accessible names and a selection border; all controls support keyboard input. Randomize changes only draft appearance, and closing the dialog discards edits. Portraits and office sprites share the renderer and appearance identity. No avatar image uploads, remote generation, standalone avatar image exports, or additional animation states in this version. Avatar settings are included in office backups.

Office backups: สำรองข้อมูล is an additional navigation item using the existing panel and button styles. Export office downloads JSON; a labeled native file input opens an import preview Dialog with counts, missing project paths, and explicit replacement confirmation. Busy controls disable repeat submission, errors use alerts, and progress/results use a live status region. Long paths wrap on mobile. Restored offices show the existing paused-team banner; schedules and Google access require manual review and enabling.
